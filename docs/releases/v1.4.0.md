## 更新内容

- 新增多选模式：Ctrl+点击切换、Shift+点击连续选择、Shift+方向键扩选；支持全选完整搜索／筛选结果、显示选择数量和批量删除，多选时双击不会粘贴。
- 单条与批量删除后 15 秒内可撤销，恢复原始图片、备注、收藏和置顶状态。删除包含收藏／置顶的记录会先确认。新一批删除会结束上一批的撤销窗口；清空历史和自动清理仍为永久删除。
- 多条文字可按选择顺序或反向顺序合并，支持换行、空格、空行、逗号和自定义分隔符，预览完整内容后复制。
- 新增来源应用、起止日期和收藏分组筛选，可与关键词、类型分类组合使用。时间范围按最近使用时间计算。
- 新增收藏分组：支持单条或批量分组、重命名与移出分组；分组时自动收藏，移除分组保留收藏记录。
- 新增「偏好设置 → 数据 → WebDAV 加密备份」：支持测试连接、创建备份、读取云端备份和合并恢复，可选恢复偏好设置。
- 备份始终在本机以 AES-256-GCM 加密，使用 Argon2id 从密码派生密钥；每份使用独立随机盐和 nonce。上传前加密，下载后验证再导入，登录密码与备份密码不会保存或写入备份。
- 备份包含历史全文、富文本、图片、备注和收藏分组。文件记录只保存路径，不上传实际文件；恢复按内容去重，本机已有记录优先。

## 安装与备份说明

下载 `Copybook_1.4.0_x64-setup.exe` 覆盖安装，或在 v1.3.0 及之后版本的「关于 → 检查更新」中更新。保留历史和设置，旧数据库自动迁移。

WebDAV 地址填写已存在的目录，远程服务需要 HTTPS（本机 loopback 测试支持 HTTP）。备份密码至少 8 字节，遗失后无法恢复。每份备份最大 256 MiB（解密后的 JSON），最多 100000 条记录；云端仍可看到文件名、大小和上传时间。

恢复采用合并方式，图片会转移至本机数据目录；本机快捷键、Win+V 接管、开机启动与管理员权限设置保留。备份不提供多设备实时同步。

## English

- Added multi-selection, complete filtered-result selection, batch deletion and a 15-second undo window including images and metadata.
- Added full-text merge preview with separators and reverse order, source/date filters, and named favorite groups with rename/ungroup actions.
- Added encrypted WebDAV backup and merge restore in Preferences → Data. Backups contain history, rich formats, images, notes, favorite groups and preferences; file entries contain paths rather than file contents.
- AES-256-GCM authenticates each backup; Argon2id derives its key (64 MiB, 3 iterations, parallelism 1). Each backup has fresh random salt/nonce. Passwords are never persisted or included in backups.
- Restore validates the password, archive and images before importing new records atomically; existing local content wins. Optional preference restore preserves local hotkeys, startup and elevation choices.

Use an existing HTTPS WebDAV collection (loopback HTTP is supported for testing). Keep your backup password: there is no recovery mechanism. Backups support at most 100000 records and 256 MiB of decrypted JSON. Remote storage can still observe encrypted file names, sizes and upload times.
