## 新增与调整

- 收藏分组改为真正的多级文件夹，最多支持 32 层目录。空文件夹也会保留，重启后不会消失。
- 在「收藏」中进入文件夹，使用面包屑或「返回上一级」导航；「全部收藏」可查看所有目录中的收藏。
- 移除原工具栏的「分组」按钮及独立管理弹窗。直接在文件夹右键菜单或「…」菜单中新建子文件夹、重命名、移动和移除；文件夹按钮获得焦点后也可按 F2 重命名。
- 单条记录右键菜单及多选工具栏改为「移至文件夹」，支持选择任意层级或收藏根目录，移动时自动收藏。
- 父文件夹重命名、移动时，其子目录和记录一并更新。移除文件夹会保留全部收藏记录，将它们移回收藏根目录。
- 搜索、来源与日期筛选、分页及全选按当前文件夹生效；鼠标及 Tab / Shift+Tab 切换分类后清除目录限制，空目录中也能切换。删除撤销保持正确的文件夹位置。
- 已有分组自动迁移，原收藏、历史与设置保留。WebDAV 备份恢复同时保存多级目录和空文件夹，继续兼容旧版加密备份。

## 安装与更新

下载 `Copybook_1.5.0_x64-setup.exe` 覆盖安装，或在「偏好设置 → 关于 → 检查更新」中更新。历史、收藏与设置保留。

## English

- Favorites now supports persistent nested folders and empty directories, with breadcrumbs and an All favorites view.
- Removed the standalone Groups button. Create subfolders, rename (F2), move or remove folders directly from their directory menus.
- Item menus and the selection toolbar now offer Move to folder. Renaming or moving a parent updates its entire subtree; removing a folder keeps its items starred at the root.
- Search, filters, pagination, select-all and delete undo respect folder locations. Existing groups migrate automatically, and encrypted WebDAV backups preserve the hierarchy and empty folders while accepting older backups.
- Install the Windows x64 installer over the current version or use the signed in-app updater. Existing history, favorites and preferences are preserved.
