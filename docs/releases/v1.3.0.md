## 更新内容

- 检查更新支持应用内下载、签名校验、自动覆盖安装和重启，无需打开浏览器、手动卸载或操作安装向导。更新时保留剪贴板历史和偏好设置。
- 下载进度支持已下载大小和进度条，下载失败、签名不匹配或安装程序无法启动时可重试，当前实例继续运行。切换设置页面不会丢失更新进度。
- 新增「偏好设置 → 通用 → 面板 → 显示来源应用」开关，统一控制历史列表和详情中的来源名称与图标；不改变记录和忽略应用的规则。
- 将「选中后直接粘贴」改为「双击直接粘贴」，行为不变，仍支持 Enter 和快捷键粘贴。
- 更新重启使用新的普通启动参数，保留原数据目录，并按持久管理员开关重新启动，避免复用失效的提权参数。

## 安装与更新

Windows 10/11 x64 下载 `Copybook_1.3.0_x64-setup.exe` 覆盖安装即可，无需先卸载，保留已有数据。
v1.2.0 及更早版本尚未包含应用内更新组件，因此本次需覆盖安装一次；从 v1.3.0 起，后续版本可在「关于 → 检查更新」中直接下载并安装。
管理员模式仍遵循 Windows UAC 授权要求。

## English

- Added in-app signed updates: download, verify, replace the installed app and restart, without a browser, manual uninstall or installer wizard. Clipboard history and preferences are preserved.
- Added progress, retry and process-wide update status that survives settings navigation. Failed downloads, signatures or installer launches leave the current instance running.
- Added a persistent Show source app switch for names/icons in history rows and details; capture and ignored-app rules are unchanged.
- Renamed the auto-paste label to Double-click to paste; behavior and keyboard shortcuts remain unchanged.
- Update restarts preserve the data directory and administrator preference without replaying stale UAC handoff arguments.

Install `Copybook_1.3.0_x64-setup.exe` once over v1.2.0 or earlier, without uninstalling. Later releases can update from Preferences → About.
