## 更新内容

- 使用新密码成功创建 WebDAV 加密备份后，Copybook 会将密码存入当前用户的 Windows 凭据管理器。下次在同一服务器目录和账号下备份时，留空密码即可。可在「偏好设置 → 数据」中忘记备份密码。
- 上传失败或恢复旧备份时，保留已有凭据。如果上传成功但保存密码失败，会分别提示备份和密码的状态。
- 多选列表只显示一个复选框。选中时在框内显示勾选标记。

在「偏好设置 → 关于 → 检查更新」升级，或下载 `Copybook_1.6.1_x64-setup.exe` 覆盖安装。

## English

- A successful WebDAV backup automatically remembers a newly entered encryption password in Windows Credential Manager for the current user. Leave the password blank next time or remove it in Settings → Data.
- Restoring a backup or failing to upload preserves the saved credential. If local credential storage fails after upload, the interface reports both outcomes.
- Multi-select rows use one checkbox with a check mark when selected.
