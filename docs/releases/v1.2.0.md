## 更新内容

- 「偏好设置 → 通用 → 以管理员权限运行」改为持久开关。开启后立即请求 Windows UAC 授权，之后每次启动、退出重开和开机自启都会按该设置提权；关闭后下次启动恢复普通权限。
- 取消首次授权会撤销开关；已开启时，启动授权被取消则退出，避免以普通权限运行。保留原数据目录和开机自启的静默行为。
- 修复本机终端中的图片双击粘贴：面板会提供带引号的绝对 PNG 路径，让 Codex CLI / Claude Code CLI 识别为图片附件，无需修改快捷键；支持中文和空格路径。
- 补充 CF_DIBV5 图片格式并保留 PNG / CF_DIB。普通图片复制与非终端粘贴继续提供原生图片格式。
- CLI 使用独立 PNG 副本，删除原历史记录不会破坏尚未发送的图片附件。

## 安装与使用

下载 `Copybook_1.2.0_x64-setup.exe` 覆盖安装，保留已有数据。支持 Windows 10/11 x64。

粘贴到 CLI：先聚焦 CLI 输入框，打开 Copybook，双击图片记录。保持「自动粘贴」开启。
支持 Windows Terminal、传统 Windows 控制台、mintty 等本机终端；系统仍会在需要时显示 UAC 授权提示。

## English

- Replaced the one-shot administrator button with a persistent switch, honored on every launch and start at login. Windows UAC approval is still required when elevating. Disabling applies to the next launch.
- Preserved the data directory and silent startup through elevation. Initial cancellation restores the switch; later startup cancellation exits rather than running unelevated.
- Fixed image double-click paste into local terminal hosts for Codex CLI / Claude Code CLI using a quoted absolute PNG path, including spaces and Unicode, with no shortcut remapping.
- Added CF_DIBV5 alongside PNG / CF_DIB. Non-terminal image pastes and copy-only actions retain native image formats.
- Kept independent PNG attachment copies so deleting a history entry does not invalidate a pending CLI attachment.

Install or update with `Copybook_1.2.0_x64-setup.exe` on Windows 10/11 x64.
