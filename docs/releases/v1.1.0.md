## 更新内容

- 新增「偏好设置 → 通用 → 以管理员权限重新启动」，通过 Windows UAC 授权后可向管理员程序自动粘贴。取消授权会保留当前实例；权限仅本次运行生效。
- 新增「偏好设置 → 关于 → 检查更新」，可手动检查新版并通过浏览器下载安装包。
- 调整 Win+V 接管逻辑：替换 F24 占位按键，只接管未附带 Ctrl、Alt、Shift 的 Win+V，按住时不再重复切换。
- 过滤面板显示期间来源未知的全屏图片，减少历史中的面板截图。
- 将「清空历史」移到剪贴板面板顶部，清空前确认，并默认保留收藏和置顶记录。
- 增大复制内容与来源信息之间的间距。

## 安装与更新

下载下方 `Copybook_1.1.0_x64-setup.exe` 并运行，可覆盖安装旧版，保留已有数据。
支持 Windows 10/11 x64，依赖系统 WebView2。

## English

- Added an explicit administrator restart in Preferences → General, with Windows UAC approval and a single-instance handoff that preserves the data directory. Cancelling keeps the current instance running.
- Added manual update checks and installer download links in Preferences → About.
- Replaced F24 placeholder input and refined bare Win+V handling; holding V no longer toggles repeatedly.
- Filtered unknown-source full-screen images arriving while the panel is visible.
- Moved Clear history into the panel header, with confirmation and starred/pinned items kept by default.
- Increased spacing between copied content and source information.

Run `Copybook_1.1.0_x64-setup.exe` to install or update on Windows 10/11 x64.
