## 修复内容

- WebDAV 新备份默认存放在所填目录下的 `copybook/` 子目录，首次使用时自动创建。如果地址已经以 `copybook/` 结尾，直接使用该目录，避免重复嵌套。
- 兼容 v1.4.0 存放在原根目录的备份，列表中标记为「旧根目录」，可继续解密恢复；不会自动移动或删除已有云端备份。
- 修复从剪贴板面板双击记录后，无法自动填入 Copybook 自身 WebDAV 地址、用户名和密码输入框的问题：设置窗口现在可以作为正常粘贴目标。
- 修复其他程序中独立对话框的粘贴目标识别。保留实际对话框及原输入控件，避免错误激活其主窗口。
- 粘贴前恢复并确认输入焦点稳定，等待 Ctrl、Shift、Alt、Win 和鼠标按键释放后，只发送一次 Ctrl+V。保留输入框原选区，避免误粘贴到其他窗口或通过重复按键造成重复内容。

## 安装与更新

下载 `Copybook_1.4.1_x64-setup.exe` 覆盖安装，或在「偏好设置 → 关于 → 检查更新」中更新。历史、收藏分组与设置保留，备份加密格式不变。

## English

- New encrypted WebDAV backups use an automatically created `copybook/` subdirectory. URLs already ending in `copybook/` are used directly. Legacy parent-directory backups remain listed and restorable without moving or deleting remote files.
- Fixed double-click paste into Copybook's own settings, including WebDAV URL, username and password fields.
- Preserve the actual foreground dialog and its original focused input instead of activating its owner window. Restore stable focus and wait for held modifiers/mouse buttons to release before sending Ctrl+V once.
- Validated repeated real-app double-click pastes, selected-text replacement, external Windows forms and owned dialogs, plus backup, UI and backend regression checks.
