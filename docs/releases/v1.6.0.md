## 收藏片段

- 在收藏根目录或子文件夹中点击「新建片段」，也可按 `Ctrl+N`。
- 右键收藏的文本，或选择后按 `Ctrl+E`，即可编辑。修改内容后以纯文本保存，备注、收藏和置顶状态保留。
- 右键「上移 / 下移」或按 `Alt+↑ / Alt+↓` 调整当前目录的顺序。置顶和普通记录分别排序。跨目录使用「移至收藏文件夹」。
- WebDAV 加密备份会保存片段和目录顺序。旧版备份仍可恢复。

## WebDAV 密码

- 在「偏好设置 → 数据」可分别记住或忘记 WebDAV 登录密码和备份加密密码。
- 密码由当前用户的 Windows 凭据管理器保存在本机，按服务器目录和用户名匹配。下次备份时留空即可使用，密码不会随备份上传。
- 在输入框填写另一个密码可临时恢复使用旧密码加密的备份。

## 安装与更新

下载 `Copybook_1.6.0_x64-setup.exe` 覆盖安装，或在「偏好设置 → 关于 → 检查更新」中更新。历史、收藏与设置会保留。

## English

- Create and edit plain-text snippets in Favorites. Use `Ctrl+N` or `Ctrl+E`.
- Move favorites between folders or reorder them with `Alt+Up` and `Alt+Down`. Pinned items keep priority. Encrypted WebDAV backups preserve snippets and folder order.
- Settings → Data can remember or forget WebDAV and backup passwords separately. They stay in Windows Credential Manager for the current user and are scoped by collection and username. Leave the fields blank to use saved passwords.
